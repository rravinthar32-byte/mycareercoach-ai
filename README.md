# Career Compass AI

Create a modern, professional web application prototype called:

“AI-Based Personalized Career Guidance System for College Students”

Purpose:

The system helps college students identify suitable career paths based on their education, skills, interests, strengths, experience, and career goals. It should provide personalized career recommendations, identify skill gaps, and create a learning plan.

Target users:

College students, especially students who are confused about choosing a career path and do not know what skills they need to develop.

Design:

- Modern AI-powered dashboard

- Clean and professional college-project UI

- Responsive web design

- Simple navigation

- Use a modern blue/purple AI-inspired visual style

- Use cards, progress bars, icons, and clear sections

- Make the prototype realistic and interactive

- Add smooth transitions where appropriate

Create the following screens:

1. LANDING / HOME PAGE

Title:

“AI-Based Personalized Career Guidance”

Subtitle:

“Discover the right career path based on your skills, interests, and goals.”

Buttons:

- Get Started

- Explore Careers

Show three feature cards:

- Personalized Career Recommendations

- Skill Gap Analysis

- AI Learning Plan

2. STUDENT PROFILE

Create a form where the student enters:

- Name

- Degree / Department

- Year of Study

- Current CGPA

- Technical Skills

- Soft Skills

- Previous Experience

- Career Goal

Button:

“Continue to Skills & Interests”

3. SKILLS & INTERESTS

Allow the student to select or enter:

Technical Skills:

- Python

- Java

- SQL

- HTML/CSS

- Machine Learning

- Data Analysis

- Cloud Computing

- Cybersecurity

Interests:

- Software Development

- Data Science

- Artificial Intelligence

- Cybersecurity

- Cloud Computing

- UI/UX Design

Also include:

- Skill proficiency level

- Areas the student enjoys

- Preferred work type

Button:

“Analyze My Profile”

4. AI ANALYSIS SCREEN

Show an AI processing animation/loading state and then display:

“Analyzing your profile…”

Analyze:

- Skills

- Interests

- Strengths

- Experience

- Career goals

After analysis, show:

“Your profile analysis is complete.”

Button:

“View Career Recommendations”

5. CAREER RECOMMENDATIONS

Display 3–4 recommended careers with matching percentages.

Example:

1. Data Scientist — 92% Match

2. Machine Learning Engineer — 87% Match

3. Data Analyst — 82% Match

4. Software Developer — 76% Match

For each career show:

- Match percentage

- Why it matches the student

- Required skills

- Career description

Button:

“View Skill Gap”

6. SKILL GAP ANALYSIS

Compare the student's current skills with the skills required for the selected career.

Example career:

“Data Scientist”

Show:

Current Skills:

- Python — Good

- SQL — Basic

- Statistics — Beginner

- Machine Learning — Beginner

- Data Visualization — Beginner

Required Skills:

- Python

- SQL

- Statistics

- Machine Learning

- Data Visualization

Use progress bars to visually show the gap.

Show section:

“Skills You Need to Improve”

Button:

“Generate Learning Plan”

7. PERSONALIZED LEARNING PLAN

Generate a personalized roadmap.

Example:

Month 1:

- Improve Python

- Learn SQL fundamentals

Month 2:

- Learn Statistics

- Practice Data Analysis

Month 3:

- Learn Machine Learning

- Build beginner ML projects

Month 4:

- Learn Data Visualization

- Build portfolio projects

For each learning item show:

- Skill

- Recommended topic

- Estimated duration

- Progress

Also include:

“Recommended Projects”

- Sales Prediction

- Student Performance Analysis

- Customer Churn Prediction

Button:

“Prepare for Jobs”

8. JOB / INTERNSHIP PREPARATION

Show personalized preparation recommendations:

- Resume improvement

- Portfolio projects

- Interview preparation

- Technical interview questions

- Communication skills

- Internship recommendations

Add buttons:

- Improve Resume

- Practice Interview

- View Projects

9. AI CAREER ASSISTANT / CHATBOT

Create a chatbot called:

“CareerAI Assistant”

The student can ask questions such as:

- “Which career is best for me?”

- “What skills should I learn next?”

- “How can I become a Data Scientist?”

- “What projects should I build?”

- “Am I ready for an internship?”

The chatbot should provide personalized answers based on the student's profile.

10. STUDENT DASHBOARD

Create a final dashboard showing:

Career Goal:

“Data Scientist”

Career Match:

92%

Overall Skill Progress:

65%

Skills Completed:

Python, SQL Basics

Skills Remaining:

Statistics, Machine Learning, Data Visualization

Learning Progress:

45%

Recommended Next Step:

“Start Statistics Fundamentals”

Also show:

- Career recommendation

- Skill gap

- Learning roadmap

- Projects

- Job preparation

- AI Career Assistant

INTERACTION FLOW:

Home

→ Student Profile

→ Skills & Interests

→ AI Analysis

→ Career Recommendations

→ Skill Gap Analysis

→ Personalized Learning Plan

→ Job/Internship Preparation

→ AI Career Assistant

→ Student Dashboard

IMPORTANT:

This is a prototype for a college Design Thinking / AI Ideation project. Focus on demonstrating the concept and user experience rather than building a real AI backend.

Use realistic sample data and make all buttons/navigation work between screens so that the complete prototype can be demonstrated during a presentation.

The main goal of the prototype is:

“Right Career → Right Skills → Right Learning Path → Better Career Preparation”
